# BarberPro ✂️

Sistema web para agendamento de horários em uma barbearia, desenvolvido com Vue 3 e Vite.

---

## 🚀 Funcionalidades

- ✅ Página inicial
- ✅ Lista de serviços
- ✅ Perfil dos barbeiros
- ✅ Agendamento de horários
- ✅ Página de contato
- ✅ Layout responsivo

---

## 🛠️ Tecnologias Utilizadas

- **Vue 3** - Framework JavaScript progressivo
- **Vite** - Build tool rápido e moderno
- **Vue Router** - Roteamento de páginas
- **CSS3** - Estilização moderna

---

## 📦 Como Executar

### 1️⃣ Clonar o projeto

```bash
git clone https://github.com/BureiLeo/Projeto-vue-js.git
```

### 2️⃣ Entrar na pasta

```bash
cd Projeto-vue-js
```

### 3️⃣ Instalar dependências

```bash
npm install
```

### 4️⃣ Rodar o projeto

```bash
npm run dev
```

### 5️⃣ Acesse no navegador

```
http://localhost:5173
```
